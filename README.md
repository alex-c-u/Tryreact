E-commerce React + Firebase

Este proyecto consiste en una tienda online desarrollada con React y Firebase, donde los usuarios pueden navegar por un catálogo de productos, visualizar su información detallada, agregar productos al carrito, aplicar cupones de descuento y finalizar una compra.

Además, el proyecto incluye un panel de gestión de productos que permite crear, editar y eliminar productos almacenados en Firestore.
Es un trabajo practico final para Talento Tech.

En el futuro le implementare más mejoras para seguir practicando y poder aprovechar al maximo todas las tecnologías.
